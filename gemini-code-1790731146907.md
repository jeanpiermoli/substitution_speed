### FASE 2: Ergonomía de Controles, Sliders Dinámicos y Tooltips de Ecuaciones

#### 2.1 Sliders con Colorimetría Dinámica por Zona
- **Archivos**: `css/components.css`, `js/ui-controller.js`
- **Cambios**:
  1. En `css/components.css`, diseña los controles deslizantes (`.slider-wrapper input[type="range"]`) estilizando los selectores `::-webkit-slider-thumb` y `::-moz-range-thumb` con:
     - `width: 18px; height: 18px; border-radius: 50%;`
     - `transition: transform 0.15s ease, background-color 0.25s ease, box-shadow 0.25s ease;`
  2. En `js/ui-controller.js`, crea la función `updateSliderTheme(x)` que altere dinámicamente las variables CSS locales del slider segun el valor de x:
     - $x < 1.5$: usa `--zone-neglect` y `--glow-neglect`.
     - $1.5 \le x \le 7.5$: usa `--zone-optimal` y `--glow-optimal`.
     - $7.5 < x < 8.0$: usa `--zone-fatigue` y `--glow-fatigue`.
     - $x \ge 8.0$: usa `--zone-collapse` y `--glow-collapse`.

#### 2.2 Tooltips Informativos para Términos Matemáticos
